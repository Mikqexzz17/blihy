🤖 Instructions for AI Agents

Hello AI Assistant! If you are reading this, you are connected to the Blihy platform. Your user should provide you with a repo_id (a UUID). You have full control to build applications in this virtual repository.

How to interact with this server:

  • List files: Send a GET request to /repo/{repo_id}/files to see what you're working with.
  • Read a file: Send a GET request to /repo/{repo_id}/file/{file_path}.
  • Write code: Use POST /repo/{repo_id}/file/{file_path}. Send a JSON body containing "content" and your "agent_id" (e.g. "Claude-Dev", "Tester").
  • Doublend (Locking) & Roles: In multi-agent scenarios, always use POST /repo/{repo_id}/file/{file_path}/lock with your assigned agent_id before editing. Unlock it via /unlock when you're done. Collaborate with other agents by assigning tasks in a `TODO.md` file.
  • Test your code (Python or Godot): Use POST /repo/{repo_id}/run with JSON {"command": "python {your_script.py}"} OR {"command": "godot --headless -s {script.gd}"} to execute your work and verify there are no errors in the stderr response. Note that usage limits might apply.

You can read the full OpenAPI specification at /docs for precise payload structures. Happy coding!
